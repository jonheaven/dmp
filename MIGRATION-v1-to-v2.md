# Moved: migrating to ÐMP 1.0

This document is now **[MIGRATION-from-draft.md](MIGRATION-from-draft.md)**.

"v1" and "v2" were working names during development. ÐMP has not launched, and its first release is
**ÐMP 1.0**. The compact signed orders (formerly "v2", now [compact-orders.md](compact-orders.md)) are
the ÐMP 1.0 listing format. The old "v1 list" is the **draft list format (pre-1.0)**. The wire bytes
did not change (`"v":"2"` and `dmp-v2-asig:` stay as they are).
